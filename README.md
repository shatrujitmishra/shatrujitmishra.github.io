# Shatrujit Mishra — Portfolio

Professional portfolio covering projects, research, education, experience, technical skills, and contact information.

The website is served directly from the main branch using GitHub Pages. No build step or external scripts are required.

## Files

- index.html: website content
- styles.css: responsive layout and typography
- main.js: navigation, project details, and email copying
- assets/: self-hosted fonts and favicon

Font licensing is documented in assets/fonts/LICENSE.txt.

Resume and manuscript requests are handled by email. The public repository contains no document PDFs.
