Project / 01

Fuzzy Logic-Based Intrusion Detection System for IoMT Networks

ANFIS-based multiclass classification of network traffic.

Method

  • Preprocessing: median imputation and Min-Max normalization.
  • Feature selection: Mutual Information to identify relevant features.
  • Class balancing: RandomUnderSampler to address class imbalance.
  • Model: gradient-based ANFIS with Gaussian membership functions.
  • Interpretation: Kernel SHAP for feature attribution.

Reported evaluation

IoMT-TrafficData dataset

96.98%Accuracy
92.33%Precision
98.23%Recall
94.58%F1-score

The reported metrics follow my résumé. Datasets used in the project: IoMT-TrafficData and WUSTL-EHMS-2020.

Project / 02

Movie Recommendation System

Content-based movie retrieval using textual metadata.

Method

  1. Use the Kaggle Movie Metadata dataset, including genres, plots, cast, and storyline descriptions.
  2. Represent the content with CountVectorizer as Bag-of-Words feature vectors.
  3. Compare movie vectors using cosine similarity to generate recommendations.
Cosine similaritysim(A, B) = (A · B) / (‖A‖ ‖B‖)

Movies with similar content have vectors pointing in similar directions. Cosine similarity measures this relationship to retrieve related titles.
